# Measurement of the galaxy bias from a catalog. 


In the file Auto_corr_FS2.py we compute the angular auto-correlation of a sample binned in magnitude and redshift range, and compare it from a halo-fit prediction. 
run python Auto_corr_FS2.py 'magmax'
Scale range in arcmin: scale_def

The bias is fitted as b(z,m)=a+(b+c.m)z^d
